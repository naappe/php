Compatibility vocabulary

VERIFIEDExact model / OEM evidence confirms the relationship.
FAMILY MATCHSame model family or catalogue relationship; installed configuration is not fully proven.
CANDIDATEPart number, description or context suggests a match.
UNVERIFIEDNo sufficient engine-specific evidence yet.
NOT COMPATIBLEEvidence excludes the relationship.

Operational values become diagnostic entry points.

No live SCADA/API connection is implemented. These are engineering links, not live alarms.

Family-level technical values must retain their operating condition and source. They are not automatically the alarm thresholds of the installed generator.
OEM Evidence Layer

Evidence is part of the data model.

The current Volvo source supports 13L family architecture, engine-data parameters, diagnostics, maintenance and selected technical data. Exact installed-model compatibility remains separately controlled.

Learning method

Study the machine before memorizing the spare.

Part learning sequence

1 · IdentifyStore item number, description and detected OEM part number.
2 · LocateEngine system → module → component location.
3 · UnderstandFunction and load/flow relationship.
4 · DiagnoseFailure clues and affected telemetry or engine behavior.
5 · VerifyCompatibility and service information against evidence.

Truth controls

Stock ≠ compatibilityA part existing in the store does not prove which engine uses it.
Family data ≠ installed limitsOperating conditions must match before a value is used as a threshold.
Diagram ≠ OEM geometrySchematics explain relationships; exact geometry requires genuine drawings/CAD.
